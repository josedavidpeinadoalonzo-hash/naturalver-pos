# Plan de Desarrollo - NaturalVer's v1.2.0

## 🎯 Objetivo
Transformar NaturalVer's en una herramienta de gestión y marketing integral, facilitando la comunicación con los clientes y la recuperación de deudas mediante la integración con WhatsApp.

## Nuevas Funcionalidades (v1.2.0)

### 1. Centro de Atención al Cliente (WhatsApp)
- [ ] **Plantillas de Mensajes**: Crear y guardar respuestas rápidas para clientes.
    - [ ] Datos de pago (Pago Móvil, transferencias).
    - [ ] Horarios y ubicación.
    - [ ] Mensaje de bienvenida/agradecimiento.
- [ ] **Catálogo Rápido**: Generar un mensaje de texto con la lista de productos y precios actuales para enviar por WhatsApp.

### 2. Gestión de Cobranza Inteligente
- [ ] **Recordatorios de Deuda**: Botón en el módulo "El Fiao" para enviar un recordatorio automático al cliente por WhatsApp.
    - [ ] Incluye: Saldo pendiente, fecha de la deuda y producto.

### 3. Reportes y Exportación
- [ ] **Cierre de Caja Detallado**: Capacidad de compartir el resumen del día por WhatsApp al administrador.
- [x] **Exportación a Excel**: Para respaldar las ventas fuera del teléfono.

### 4. Experiencia de Usuario (UX)
- [ ] **Buscador de Productos**: Filtro rápido en la lista de productos y en la pantalla de venta.
- [ ] **Mejora en Categorías**: Poder añadir/editar categorías personalizadas.
